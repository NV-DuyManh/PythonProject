# Connecting GitHub to CodeGate (End-User Guide)

CodeGate integrates seamlessly with your GitHub Personal or Organization account using a secure, dynamic GitHub App flow. You do **not** need to manually generate Personal Access Tokens (PATs) or edit any `.env` files.

## Prerequisites
- You must be signed in to CodeGate.
- You must have selected the Workspace you want to connect to GitHub.

## How to Connect

1. **Sign in** to your CodeGate dashboard.
2. Select your **Workspace** from the top-left switcher.
3. Navigate to **Integrations** from the sidebar.
4. Click the **Connect GitHub** button.
5. You will be redirected to the official GitHub website.
6. **Choose the account or Organization** you want to install CodeGate on.
7. Choose repository permissions:
   - **All repositories**: CodeGate will automatically have access to all current and future repositories in that account.
   - **Only select repositories**: Choose exactly which repositories CodeGate is allowed to analyze.
8. Click **Install & Authorize**.
9. You will be redirected back to CodeGate, and your new connection will appear as an active card in the Integrations list.

Your GitHub connection is now fully established and isolated to your active Workspace.

# Project Structure

- `codegate/` - CodeGate platform services, persistence, scoring, and orchestration.
- `dashboard/` - React/Vite web interface.
- `pr_agent/` - Upstream AI PR review core.
- `tests/` - Pytest suites.
- `alembic/` - Database migrations.
- `scripts/` - Utility scripts.
- `tools/codegate_launcher/` - Python GUI launcher for Windows.
- `docs/` - System documentation.

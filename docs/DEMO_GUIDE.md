# Demo Guide

## Presentation Flow (5-8 minutes)

1. Start `CodeGateLauncher.exe` and click START.
2. Open Dashboard (`http://127.0.0.1:5173/dashboard`).
3. Explain the isolation between **Demo** and **Live** data.
4. Navigate to a test Repository.
5. Open a Pull Request.
6. Show the **AI Review** feedback.
7. Detail the **Quality Score** dimensions.
8. Detail the **Risk Score** factors.
9. Explain the active **Merge Policy**.
10. Show the synchronized **GitHub Check**.
11. View detailed PR evidence (Findings, Tests, Coverage, Reviewers).
12. Check global **Analytics**.

## Scenario Demonstration
- **PASS:** High Quality, Low Risk, tests pass.
- **WARNING:** Medium Risk or some Code Quality issues, no blocks.
- **BLOCK:** Critical security finding or failing tests triggering a hard block.

*(If external APIs fail, utilize seeded DEMO data).*
